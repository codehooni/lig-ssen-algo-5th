## 문제 요약

입력된 아이디에 정해진 7단계 규칙을 순서대로 적용해, 규칙에 맞게 바뀐 추천 아이디를 반환한다.

## 입출력 조건

- 아이디 길이: 1 ~ 1,000
- 알파벳 대소문자, 숫자, 특수문자로 이루어진다.
