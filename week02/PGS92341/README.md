# 주차 요금 계산

## 문제 요약

요금표와 하루 동안의 입차/출차 기록이 주어질 때, 차량 번호가 작은 순서대로 각 차량의 주차 요금을 반환한다.

## 입출력 조건

- 요금표: 기본 시간, 기본 요금, 단위 시간, 단위 요금 4개 값
- 기록 개수: 1 ~ 1,000
- 기록은 `시각(HH:MM) 차량번호 IN/OUT` 형식이며, 차량 번호는 4자리 숫자다.
- 출차 기록이 없는 차량은 23:59에 출차한 것으로 본다.
