## 문제 요약

`(`와 `)`로만 이루어진 문자열이 짝이 맞는 괄호인지 판별해 `true`/`false`를 반환한다.

## 입출력 조건

- 문자열 길이: 100,000 이하
- 문자열은 `(`와 `)`로만 이루어진다.
