## 문제 요약

19×19 바둑판에 놓인 검은 바둑알과 흰 바둑알의 상태가 주어질 때, 같은 색 바둑알 정확히 5개가 가로/세로/대각선으로 연속하여 놓인 쪽을 승자로 판정한다. 승자와 연속된 다섯 알 중 가장 왼쪽(세로일 경우 가장 위쪽) 바둑알의 위치를 출력하고, 승부가 나지 않았다면 0을 출력한다.

## 입출력 조건

- 바둑판 크기: 19×19
- 검은 알은 1, 흰 알은 2, 빈 칸은 0으로 주어진다.
- 6개 이상 연속된 경우는 이긴 것으로 보지 않는다.
- 검은색과 흰색이 동시에 이기거나 두 군데 이상에서 이기는 경우는 입력으로 주어지지 않는다.
