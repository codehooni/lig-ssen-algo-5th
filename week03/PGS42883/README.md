# 큰 수 만들기

## 문제 요약

숫자 문자열 number에서 k개의 수를 제거했을 때 만들 수 있는 가장 큰 수를 문자열로 반환한다.

## 입출력 조건

- number: 2자리 이상, 1,000,000자리 이하의 숫자
- k: 1 이상, number의 자릿수 미만인 자연수
