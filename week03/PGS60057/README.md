## 문제 요약

문자열을 1개 이상의 단위로 잘라 연속해서 반복되는 부분을 "반복 횟수 + 문자열" 형태로 압축할 때, 만들 수 있는 가장 짧은 압축 문자열의 길이를 반환한다.

## 입출력 조건

- 문자열 s 길이: 1 ~ 1,000
- s는 알파벳 소문자로만 이루어진다.
- 문자열은 앞에서부터 정해진 길이만큼 잘라야 한다.
