# 정찰 드론의 레이더 돌파

| 폴더 | 문제 | 출처 | 주제 |
| --- | --- | --- | --- |
| Test1-1 | 정찰 드론의 레이더 돌파 | 261123_Set1 | BFS |

## 문제 설명

정찰 드론이 출발 지점에서 목표 지점까지 이동하려고 합니다. 작전 지역은 `n × m` 격자로 주어지며, 문자열 배열 `field`의 `field[i]`의 `j`번째 문자가 `i`행 `j`열 칸을 나타냅니다.

| 문자 | 의미 |
| --- | --- |
| `S` | 출발 지점 (정확히 1개) |
| `E` | 목표 지점 (정확히 1개) |
| `.` | 빈 칸 |
| `#` | 건물 (진입 불가) |
| `R` | 적 레이더 구역 |

드론은 한 번에 **상하좌우**로 인접한 칸 하나로 이동하며, 격자 밖이나 건물 칸으로는 이동할 수 없습니다.

레이더 구역 칸은 지날 수 있지만, 레이더 구역 칸에 **들어갈 때마다** 전파 재밍 장비를 1회 사용해야 합니다. 같은 레이더 구역 칸에 다시 들어가도 다시 1회를 사용합니다. 재밍 장비는 작전 전체에서 **최대 `k`회**까지만 사용할 수 있습니다.

드론이 `S`에서 `E`까지 가는 데 필요한 **최소 이동 횟수**를 반환하세요. 어떤 방법으로도 도착할 수 없다면 `-1`을 반환하세요.

## 제한사항

- `1 ≤ n ≤ 100` (`n`은 `field`의 길이)
- `1 ≤ m ≤ 100` (`m`은 `field[i]`의 길이이며 모든 행의 길이는 같습니다)
- `field`는 `S`, `E`, `.`, `#`, `R`로만 이루어져 있으며, `S`와 `E`는 각각 정확히 하나씩 있습니다.
- `0 ≤ k ≤ 10`

## 함수 형식

```cpp
int solution(vector<string> field, int k)
```

## 입출력 예

| field | k | result |
| --- | --- | --- |
| `["S.R..", ".#R#.", ".#R#.", ".#...", "...#E"]` | `1` | `8` |
| `["SRRE"]` | `1` | `-1` |
| `["S.R..", ".#R#.", ".#R#.", ".#...", "...#E"]` | `0` | `10` |

## 입출력 예 설명

**입출력 예 #1**

맨 윗줄을 따라 오른쪽 끝까지 간 뒤 오른쪽 열을 따라 내려가면, `(0, 2)`의 레이더 구역을 한 번만 지나 8번 만에 도착합니다. 재밍 1회로 충분하므로 최소 이동 횟수는 8입니다.

**입출력 예 #2**

`E`에 가려면 레이더 구역 2칸을 반드시 지나야 하지만 재밍은 1회만 가능하므로 도착할 수 없습니다.

**입출력 예 #3**

예제 1과 같은 지형이지만 재밍을 쓸 수 없습니다. 왼쪽 열을 따라 내려간 뒤 아래쪽으로 레이더 구역을 피해 돌아가면 10번 만에 도착합니다.
