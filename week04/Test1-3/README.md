# 압축 통신 신호 복원

| 폴더 | 문제 | 출처 | 주제 |
| --- | --- | --- | --- |
| Test1-3 | 압축 통신 신호 복원 | 261123_Set1 | 스택, 문자열 |

## 문제 설명

전술 통신망은 대역폭을 아끼기 위해 반복되는 신호를 압축해서 보냅니다. 압축 규칙은 다음과 같습니다.

- `x[A]`는 문자열 `A`를 **`x`번 반복**한 문자열을 뜻합니다. `x`는 1 이상의 정수이며 두 자리 이상일 수 있습니다.
- `A` 안에 다시 `y[B]` 형태가 들어갈 수 있습니다. 즉, 압축은 **여러 겹으로 중첩**될 수 있습니다.
- 압축되지 않은 영문자는 그대로 이어 붙입니다. 영문 대문자와 소문자는 서로 다른 문자로 취급하며 그대로 보존합니다.

예를 들어 `2[a2[b]]c`는 `abbabbc`로 복원됩니다.

압축된 신호 `code`가 주어질 때, 원래 신호를 복원한 문자열을 반환하세요.

## 제한사항

- `1 ≤ code의 길이 ≤ 30,000`
- `code`는 영문 대소문자, 숫자, `[`, `]`로만 이루어져 있습니다.
- `code`는 항상 올바른 압축 형식입니다. 숫자는 반드시 바로 뒤에 `[`가 오는 반복 횟수로만 쓰이며, 모든 `[`와 `]`는 올바르게 짝지어져 있습니다.
- 반복 횟수는 `1` 이상 `100` 이하의 정수이며 `0`으로 시작하지 않습니다.
- 모든 `[` `]` 안에는 최소 한 개의 영문자가 들어 있습니다.
- 복원된 문자열의 길이는 `1` 이상 `100,000` 이하입니다.

## 함수 형식

```cpp
string solution(string code)
```

## 입출력 예

| code | result |
| --- | --- |
| `"3[ab]c"` | `"abababc"` |
| `"2[a3[bC]]d"` | `"abCbCbCabCbCbCd"` |
| `"x10[y]z"` | `"xyyyyyyyyyyz"` |

## 입출력 예 설명

**입출력 예 #1**

`3[ab]`는 `ab`를 3번 반복한 `ababab`이고, 뒤에 `c`가 붙어 `abababc`가 됩니다.

**입출력 예 #2**

안쪽의 `3[bC]`가 먼저 `bCbCbC`로 바뀌어 `a` 뒤에 붙고, 이 `abCbCbC`가 2번 반복된 뒤 `d`가 붙습니다. 대소문자는 그대로 유지됩니다.

**입출력 예 #3**

반복 횟수는 두 자리 이상일 수 있습니다. `10[y]`는 `y`를 10번 반복한 문자열입니다.
