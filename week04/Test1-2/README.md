# 레이저 대공 방어

## 문제 설명

적 드론 `n`대가 방어 구역을 통과합니다. `drones[i] = [s, e]`는 `i`번 드론이 시각 `s`부터 시각 `e`까지(**양 끝 포함**) 레이저 포대의 사거리 안에 머문다는 뜻입니다.

레이저 포대는 한 번 가동하면 정확히 `d`만큼 유지됩니다. 즉, 시각 `t`에 가동하면 시각 `t`부터 `t + d`까지(**양 끝 포함**) 레이저가 켜져 있습니다. 레이저가 켜져 있는 동안 **한 순간이라도** 사거리 안에 있는 드론은 모두 격추됩니다.

가동 시각 `t`는 원하는 정수 시각으로 정할 수 있고, 여러 번의 가동 구간이 서로 겹쳐도 됩니다.

모든 드론을 격추하기 위해 레이저 포대를 가동해야 하는 **최소 횟수**를 반환하세요.

## 제한사항

- `1 ≤ n ≤ 100,000` (`n`은 `drones`의 길이)
- `drones[i]`는 `[s, e]` 형태이며 `0 ≤ s ≤ e ≤ 2,000,000,000`
- `0 ≤ d ≤ 2,000,000,000`
- 여러 드론의 구간이 같을 수 있습니다.

## 함수 형식

```cpp
int solution(vector<vector<int>> drones, int d)
```

## 입출력 예

| drones | d | result |
| --- | --- | --- |
| `[[1, 3], [4, 6], [10, 12], [13, 15]]` | `2` | `2` |
| `[[0, 10], [2, 3], [5, 6], [8, 9]]` | `0` | `3` |
| `[[5, 5]]` | `100` | `1` |

## 입출력 예 설명

**입출력 예 #1**

시각 3에 가동하면 `[3, 5]` 동안 가동되어 1, 2번 드론을, 시각 12에 가동하면 `[12, 14]` 동안 가동되어 3, 4번 드론을 격추합니다. 한 번의 가동으로 네 대를 모두 격추할 수는 없으므로 답은 2입니다.

**입출력 예 #2**

`d = 0`이므로 가동한 그 순간에 사거리 안에 있는 드론만 격추됩니다. 시각 3, 6, 9에 가동하면 모든 드론을 격추할 수 있고, 2회로는 불가능합니다.

**입출력 예 #3**

드론이 한 대뿐이므로 한 번만 가동하면 됩니다.
